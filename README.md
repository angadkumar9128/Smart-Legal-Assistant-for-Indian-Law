# 🇮🇳 Smart Legal Assistant for Indian Law

The **Indian Legal Intelligence Platform** is an AI-powered web application designed to provide comprehensive, easily digestible legal assistance based on the **Indian Constitution**, **Indian Penal Code (IPC)**, and other central and state laws. It uses cutting-edge technologies like **Next.js**, **React**, **TypeScript**, **GPT-3.5**, and **Pinecone** to deliver human-like legal interaction and deep search capabilities.

---

## 🚀 Features

### 🧠 AI-Powered Legal Insights
- Get answers to legal questions using natural language.
- Context-aware legal explanations from verified law content.
- Easy-to-understand summaries of complex legal provisions.

### 🏛️ Based on Indian Laws
- Covers Constitution of India, Indian Penal Code (IPC), and other important acts.
- Specific insights into individual rights, criminal law, civil law, and legal processes.

### 🌐 Multi-Language Support
- Legal answers and documentation available in **multiple Indian regional languages** (e.g., Hindi, Tamil, Bengali).
- Promotes legal literacy across diverse linguistic communities in India.

### 📹 Educational Resources
- Access **legal education videos** to understand complex topics visually.
- Learn about real-world case applications and how laws are enforced.

### 📄 Legal Documentation
- View or download simplified legal documents.
- Assistance in generating templates for FIRs, complaints, and affidavits.

### 🌍 Region-Specific Explanations
- Custom legal insights based on **state-specific laws and policies**.
- Hyper-local legal awareness initiatives made accessible.

## 📦 Installation & Setup

> _Note: Development setup instructions only. Production deployment may vary._

1. **Clone the repository**
   ```bash
   git clone https://github.com/angadkumar9128/Smart-Legal-Assistant-for-Indian-Law.git
   cd Smart-Legal-Assistant-for-Indian-Law


2. Install dependencies

npm install

Set up environment variables

Create a .env.local file and add:

NEXT_PUBLIC_OPENAI_API_KEY=your_openai_key

NEXT_PUBLIC_PINECONE_API_KEY=your_pinecone_key

NEXT_PUBLIC_PINECONE_ENVIRONMENT=your_env

NEXT_PUBLIC_PINECONE_INDEX=your_index_name

npm run dev

Visit http://localhost:3000 to use the app locally.
